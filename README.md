# programinhas-md
Repositório de programinhas para  Matemática  Discreta

Programa 1: Calcula o  valor lógico de: p or (q and r)
Programa 2: Gera uma tabela-verdade baseado no programa 1
Programa 3: Permite a inserção de elementos para conjunto A|B e realiza operações de União, Intersecção e Diferença
Programa 4: Calcula a cardinalidade de um conjunto dado pelo usuário
Programa 5: Verifica se um conjunto B é subconjunto de A. Ambos conjuntos são dados pelo usuário
